# Mimir documentation

The agent-facing contract and its design constraints live in
[agent-interface.md](agent-interface.md).

Closed Activity sessions are accessed through Cmd/Ctrl+P → History (`@`).
History resumes only an exact recorded provider session; otherwise it restores
the saved transcript without starting a different session.

Dense system notes, delivery records, and tutorials are preserved in
[reference/](reference/README.md). Search that archive only when code and
focused help do not answer the question.

For team communication, client behavior, the Ergo deployment, account
operations, and chat-linked agents, see [Chats](reference/chat.md).
